# Frontend - Sistema Hospitalario HRO

Módulo cliente desarrollado en **React** con **TailwindCSS** y **Vite**.

### Estaciones / Módulos de Usuario:
1. **Estación de Enfermería** (`desktop`): Búsqueda de pacientes, confirmación de cita, agregar a cola y visualización de órdenes de laboratorio.
2. **Estación de Archivo** (`mobile`): Localización de expedientes físicos y actualización de estados.
3. **Panel de Administración** (`desktop / mobile`): Gestión de clínicas, especialidades, médicos, cupos, calendario, reportes y auditoría.
4. **Tablero de Turnos** (`smart tv / fullscreen`): Visualización pública de turnos en tiempo real mediante WebSocket.
